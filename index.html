02 / 04 — The planning problemDefine the model

Language models + problem formulation

Make the rules
explicit.

An operational request rarely specifies every rule. The agent uses a language model to structure the request, asks about missing information, and confirms ambiguous constraints before solving.

  1. 01Extract resources, required work, and priorities from the request.
  2. 02Ask which rules are mandatory and which goals can be traded off.
  3. 03Express the agreed rules as decision variables, constraints, and an objective.
The same dispatch problemRequest → Model
Illustrative request
“Cover all three visits this morning. Keep travel time low.”
Clarify before solving

Can a team cover more than one visit in this time window?

Confirmed: No. At most one visit per team.

Decision variables
assign[team, visit] ∈ {0, 1}
Choose the team assigned to each visit.
Hard constraints
  • Exactly one team per visit.
  • At most one visit per team.
  • Only available teams may be assigned.
Objective
min Σ travel[team, visit] × assign[team, visit]

The model states what must hold and what the solver should improve.

The solver returns an allocation and its objective value. The agent checks the result against the model, presents it for review, and uses connected tools to carry out approved actions.
