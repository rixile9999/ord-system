01 / 05 — Operations Research & Decision운영 맥락에서 model로

01 / Problem formulation

운영 의도를
명시적인 model로.

운영 지식은 언어, 데이터, 규칙에 흩어져 있습니다. Language model은 이 맥락을 정리하고, 검토와 계산이 가능한 수학적 문제로 표현하는 과정을 돕습니다.

Grounding
요구사항을 운영 데이터 및 도메인 정의와 연결합니다.
Clarification
누락된 정보와 모호한 규칙을 확인하여, 확인되지 않은 가정이 model에 들어가지 않도록 합니다.
02 / 05 — Context → ModelModel에서 해의 계산으로

02 / Mathematical optimization

Feasibility를 정의하고,
의사결정을 최적화합니다.

Solver는 명시된 constraints 안에서 해를 탐색합니다. Objectives는 가능한 대안을 어떤 기준으로 비교하는지 검토할 수 있게 합니다.

Feasibility
Model에 정의된 constraints를 만족하는지 확인합니다.
Objective value
명시한 평가 기준으로 각 후보 해를 평가합니다.
Trade-offs
상충하는 목표를 weights, priorities 또는 대안 scenario로 명시합니다.
03 / 05 — Model → Solution계산 결과에서 실행으로

03 / Agentic orchestration

이해하고, 계산하고, 실행하며.
변화에 맞춰 다시 판단합니다.

Agent는 language model, solver, 운영 tools를 연결합니다. State를 유지하고 결과를 확인하며, 새로운 정보와 운영 상황에 따라 다음 행동을 선택합니다.

Tool use + state management
Model 구성부터 계산과 실행까지 맥락을 유지합니다.
Validation + replanning
Solver status와 운영 요구사항을 확인하고, 조건이 바뀌면 model을 다시 검토합니다.
04 / 05 — Solution → Action → Feedback실제 플랫폼으로 이어보기

04 / The platform in practice

RN-AI.
간호사 근무표를 위한
agentic AI.

기존 엑셀에서 시작해 검토 가능한 근무표 초안까지. 채팅 요청과 화면 편집을 병동 데이터, 명시적인 근무 규칙, CP-SAT 기반 계산으로 연결합니다.

Context-aware tools
UI와 agent가 간호사·근무코드·희망근무를 다루는 domain services를 공유합니다. 현재 화면의 context를 대화에 반영합니다.
Constraint programming
필요 인력, 근무 패턴, 숙련도, 선호를 hard constraints와 weighted penalties로 표현하고 OR-Tools CP-SAT으로 계산합니다.
Solver-independent evaluation
생성한 초안과 수정한 근무표의 규칙 위반 및 penalty를 새 optimization 없이 평가할 수 있습니다.
