# ORD Systems — 2안

Operations Research & Decision을 바탕으로 새로 만든 vector symbol과 wordmark다.

symbol의 경계는 목표와 제약으로 정의한 feasible region을 나타낸다. 경계 위의 파란 점은 선택된 decision을 나타낸다. symbol의 중심을 비워 O의 형태도 함께 읽히도록 설계했다.

wordmark의 O는 symbol을 사용하고, R과 D는 같은 높이와 두께를 기준으로 만든 vector path다. 기존 로고의 path나 font glyph를 가져오지 않았다.

- `ord-symbol.svg`: 작은 크기에 사용하는 symbol
- `ord-wordmark.svg`: ORD wordmark
- [Homepage 2안](../../designs/decision-field.html): 새 typography, 색상, layout과 함께 적용한 화면

회사의 핵심은 mathematical optimization과 language model을 융합해 복잡한 운영 문제를 효율적으로 최적화하는 agentic AI다. RN-AI는 실제 서비스로 짧게 소개한다.
